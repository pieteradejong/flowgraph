# FlowGraph Roadmap

## Phase 1 — Local Simulator (current)
- Graph editor (nodes + edges)
- Simulation step engine
- Edge utilization visualization
- Metrics panel
- Sample graph

## Phase 2 — Persistence (Supabase)
- Save/load simulations
- Graph versioning
- Basic auth

## Phase 3 — Simulation Runs
- Store run results
- Replay runs
- Compare runs

## Phase 4 — Scenarios
- Prebuilt templates:
  - data center
  - satellite network
  - logistics system

## Phase 5 — Advanced Simulation
- backpressure
- queueing
- failures
- latency propagation

## Phase 6 — Visualization
- time-series charts
- heatmaps
- bottleneck highlighting
